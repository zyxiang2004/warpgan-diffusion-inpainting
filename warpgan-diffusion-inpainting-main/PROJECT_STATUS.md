## 1. 项目要解决的问题，以及总体思路

**问题**：给定一张真实人脸照片，以及它的相机参数和深度图（3D 几何已知），生成
同一个人在另一个相机视角下的照片。把照片按几何投影到新视角后，会有一部分区域
没有任何像素覆盖（称之为"空洞"或 hole，例如转头后露出的另一侧脸颊）。**这些空洞
区域在现实中不存在对应的真实照片**——那个角度没有被拍过。这是整个项目所有设计
困难的来源。

**原版方法（本项目要改造的对象）**：原版 WarpGAN（NeurIPS 2025，代码副本在
`reference/orig_WarpGAN-main/`）先用一个 3D GAN（EG3D）把照片编码成潜码并渲染出
新视角的草图，再把照片像素按几何投影（warp）到新视角，最后用一个前馈网络
（FFC-ResNet，代码里叫 inpaintor 或 SVINet）把破碎的投影图修补成完整图像。原版
的问题：输出虽然结构和身份正确，但质感平滑、缺乏真实照片的皮肤纹理——项目内部
称这种现象为"油画感"。

**我们的目标（老师确定的方案，2026-08-23 定稿，原文见
`reference/docs_archive/ORIG_FAITHFUL_PORT_SPEC.md`）**：保留原版的几何流程和训练
数据组织方式，只把 FFC-ResNet 修补器替换成一组 diffusion 组件：冻结的 Stable
Diffusion 1.5 UNet 作为生成主干、BrushNet（一种 ControlNet 变体）提供条件控制、
通过注意力机制从参考图片注入纹理、通过 cross-attention 注入身份潜码（W+ codes）。
其余一切（数据流、损失的位置、监督目标的来源）保持原版语义。

## 2. 术语表（先读这一节，后文所有术语在此定义）

| 术语 | 含义 |
|---|---|
| warp / forward_warp | 把图像像素按深度和相机参数投影到另一视角（`utils/warp/Splatting.py`），投影不到的区域形成空洞 |
| hole / 空洞 / 盲区 | warp 后无像素覆盖、需要"无中生有"补出的区域 |
| pass1（第一次前向） | 输入新视角破损图，输出新视角修补结果。**没有真实照片可对照** |
| pass2（第二次前向） | 把 pass1 的条件图再 warp 回源视角做重建。**有真实照片可对照**，是照片监督的落点（沿用原版设计） |
| warp_warp_img | 源照片 warp 到新视角、再 warp 回源视角的结果，即 pass2 的输入条件。老师指定它作为参考特征的输入 |
| x_mirror | 源照片的水平翻转=镜像视角的真实照片，是空洞内容最接近的真实证据 |
| y_hat / y_hat_novel | EG3D 渲染的重建图（源/新视角）：几何可信，质感失真 |
| W+ codes | EG3D 潜码（14×512），携带身份与视角信息 |
| bank（参考特征库） | 参考图过冻结 UNet 后各注意力层存下的特征；去噪时同层检索注入（`models/referencenet/attention_processor.py`，写入见 `_write_bank`） |
| anchor | pass1 的训练目标图：照片证据与渲染按深度一致性连续混合（`_build_novel_view`） |
| ε-MSE | diffusion 标准损失：预测所加噪声，MSE 衡量 |
| x0 预测 | 由加噪图与预测噪声反解的"干净图"估计 |
| FM / 对抗损失 | 特征匹配 / 判别器损失，把输出的统计分布拉向真实照片 |
| 对称重加噪 | 当前版本核心机制，见 §4.3 |
| 手工门 | 项目内部对"人为硬编码阈值"的统称（t<200 门、频段切分等），当前版本已全部移除 |
| "沙沙感" | 用户对主要缺陷的描述：空洞区出现细密高频噪点，量够但不是此人真实纹理 |

## 4. 当前代码的架构（代码里实际存在的形态）

### 4.1 模块组成（`training/coach_inpainting_diffusion.py`，`Coach.__init__`）

**冻结不训练的部分**：Stable Diffusion 1.5 的 VAE 和 UNet、空文本提示的 CLIP 编码、
GOAE/EG3D 反演网络（只在启用 latent 闭环损失时加载）、两个 warp 工具。VAE 和 UNet
设为 train 模式并开启梯度检查点——这不是为了训练它们，而是让梯度能穿过它们回传
到 BrushNet，同时省显存（网络本身无 BatchNorm 统计问题，train 模式数值不变）。

**参与训练的部分**：BrushNet（用官方 inpainting 预训练权重初始化，是唯一的大模块）；
安装在 SD UNet 每个注意力层上的 `ReferenceAttentionProcessor`（其中纹理检索的
K/V/O 适配器约 37M 参数、mirror 独立 K/V 约 25M 参数）；可选的判别器（NLayer
PatchGAN，约 7M 参数，当前配方启用）。W+ 的投影层（`wplusnet`→`w_proj`）使用早期
预训练的权重并冻结（开关 `wplus.mode: frozen`，其他档位见 §6）。

### 4.2 一次训练迭代的数据流（真实批与合成批 1:1 交替，各自独立做优化器步）

**真实照片批，第一次前向（pass1，新视角）**：
输入条件 = warp 可见区 + EG3D 新视角渲染填洞的混合图（条件端的掩码做了腐蚀+模糊
软化，这是原版的处理方式）；参考特征库的主源是镜像照片 x_mirror、副源是新视角
渲染；损失 = 对 anchor（§2 术语表）做单一全带的 ε-MSE。

**真实照片批，第二次前向（pass2，回源视角）**：
把 pass1 的条件图再 warp 回源视角作为输入（即 warp_warp_img），用源视角渲染填洞；
参考特征库的主源是 warp_warp_img（老师指定的），副源是源视角渲染；损失 = 对**真实
照片 x** 的全帧 ε-MSE，加上下述 x0 分布监督。这一步的含义是：新视角没有真值，
但把任务转回源视角后就有真值了，网络在源视角学到的"把破损图修成真实照片"的
能力，会迁移到新视角的使用中（原版正是这样设计的）。

**合成批**：
数据是 EG3D 对同一虚拟身份渲染的双视角精确配对（输入视角图 + 目标视角图都有）。
ε-MSE 全带地对配对渲染；x0 分布监督的"真实"参照用的是该身份的**源照片**
（合成数据的源图也是 EG3D 渲染的，但统计上更接近照片分布；这是有意的选择，
理由见 §5.3 证据分级）。W+ 身份分支只允许在这一批更新（真实批上会积累错误
梯度，这是历史教训，见 §6 红线）。

### 4.3 x0 对称重加噪分布监督（`Coach._x0_losses`，当前版本的核心新增）

**要解决的问题**：ε-MSE 是回归损失，它能教会网络"结构长什么样"和"高频能量有多
少"，但教不会"这块区域此刻应该是什么质感的纹理"——这种知识只能来自真实照片的
统计分布，也就是需要判别器类损失。历史上（v14 及更早）把这类损失直接加在 x0
预测图上会训练崩溃，原因有二：一是参照对视角不匹配，判别器会先学会用"视角对
不对"这种与目标无关的线索区分真假，然后给生成器的梯度就全错了；二是 x0 预测
图在高噪声 timestep 上含大量残噪，判别器同样会走"看噪声水平"的捷径。

**机制**（无任何人手设定的阈值）：
```
x0_hat = (x_t − √(1−ᾱ_t)·ε_pred) / √ᾱ_t        ← 从噪声预测反解干净图
fake_t = √ᾱ_t·x0_hat + √(1−ᾱ_t)·ε_new          ← 把干净图重新加噪到与 x_t 相同水平
real_t = x_t（真实批）/ 同样方式加噪的照片（合成批）
```
判别器与特征匹配损失比较的是 (fake_t, real_t) 这一对。因为两边噪声水平相同，
判别器无法用噪声区分真假，只能看内容与质感；当 timestep 趋近最大值时，两边都
退化为纯噪声，监督自动失效（不再需要"只在 t<200 施加"这种人为限制）；梯度经过
fake_t 的构造式自动带上 √ᾱ_t 因子（等效于信噪比加权，无需手写权重）。像素 L1
损失的权重也取解析值 ᾱ_t。

**被移除的历史机制**（代码路径保留、由 `losses.x0.enable` 开关旁路，可回退对照）：
t<200 timestep 门、x0 截断值 3.0（现放宽为 8.0 仅作数值保护）、按 σ=2 潜空间像素
划分结构/纹理频段的监督方式、双频带加权（dual-band）及其 13 像素过渡带、随机
patch 解码与 L1×2 权重。移除理由：它们都是分布监督缺席时期的替代品，用户指出
这些"手工门"不符合第一性原理；分布监督回归后由其取代。

## 5. 项目历史（三个多月，四十多个版本）

历史分三个阶段。前两个阶段的详细记录在 `reference/docs_archive/`（其中
`PROJECT_HISTORY.md` 是早期历史，`STEP0_SMOKE_REPORT.md` 是移植后的逐轮记录，
`README.md` 有版本一览表）。**注意：旧文档中至少有两处根因分析后来被推翻**
（§8.44 与 §8.47 的结论均被后续勘误修正），所以旧文档只能当事实记录看，
其中的分析结论要以代码和对照数据为准。

### 5.1 第一阶段：早期自研（2026-05 ~ 08-23）

从零搭建自己的 diffusion 方案，尝试了联合训练、双分支结构、各种频段监督、可训练
W+ 分支等大量方向，四个月未达到可接受的效果。这一阶段的价值是沉淀了 22 条
被证伪的方向清单（`PROJECT_HISTORY.md` §4）——后续所有版本都靠这份清单避免
重复踩坑。

### 5.2 第二阶段：忠实移植与逐版本迭代（08-23 ~ 09-08）

按老师的五句话规格把原版翻译成 BrushNet + SD1.5（代码结构就是现在这份），然后
以"每次只改一个变量"的方式迭代了约 16 个版本：

| 版本 | 改动 | 结果 |
|---|---|---|
| step1b | 纯 ε-MSE 基线（25K 步） | 成为后续所有版本的对照基线 |
| v1-v3 | 加入镜像照片参考 | 整代无效——续训时命令行参数覆盖丢失的事故 |
| v4-v7a | 镜像监督方式的一系列修正 | 修复了大量实现问题，效果趋于稳定 |
| v8 | 删除独立的参考网络，改用主 UNet 自身存特征 | 与原方案像素级等价，省下 860M 参数 |
| v9 | 合成批只监督结构频段 + 镜像照片作为主参考源 | 微小改善 |
| v10 | 条件端掩码软化（原版语义） | 负结果：证明条件端不是接缝问题的瓶颈 |
| v11 | 空洞零监督 + 局部检索窗口 | 失败：盲区高频漂移被实测 |
| v12 | 盲区低频锚定（dual-band） | 用户裁决为当时最好的结构，但"沙沙感"未解决 |
| v13 | 恢复原版全部损失项 | 失败：v12 优于 v13 |
| v14 | 加入 GAN/FM（参照对视角错位） | 训练崩溃（判别器走了视角捷径） |
| v15 | 盲区高频保持约束 | 失败 |
| v16 | pass2 像素回流（t<200 门控的 L1） | 与 v12 指标无差异（本次对话核实） |

这个阶段的普遍模式：每一版训练约 17-24 小时，裁决依赖肉眼观察和不敏感的 L1
指标，而且**从未与原版输出做过对照**。

### 5.3 第三阶段：诊断转折（09-08 ~ 09-09，产生当前代码）

1. **第一次与原版做基准对比**。按老师要求"可视化要对比原版结果、多看不同
   case"，写了 `scripts/eval_anchor_compare.py`：原版 FFC 模型（权重
   `pretrained_models/inpaintor.pt`）与 v16、v12 在同一批 24 个测试样例上
   （8 个身份 × 3 视角，空洞占比 0.03 到 0.68）用相同随机种子生成并对比。
   第一次运行时 FFC 的推理复现有 bug（混合条件图的可见区误用了原图而不是
   warp 后的图），**用户看图发现"人脸是原来角度的"而定位了这个问题**，修复后
   重跑。数据在 `experiments/anchor_compare/`。

2. **对比结果**（`anchor_metrics.txt`）：原版在像素保真上全面领先（空洞区 L1
   0.074 vs 我方 0.087/0.089）；原版空洞区高频能量只有真实照片的 36%，但用户
   终审确认它的质感是"内容自适应"的——该模糊的地方（虚化的背景）就生成模糊，
   轮廓自然；我方高频能量与照片相当，但用户三轮肉眼终审确认内容是错的
   （"沙沙感"），且高频超标的样例与沙沙位置吻合。用户还确认了一个此前不知道
   的问题：训练目标图 anchor 本身在空洞大时是破碎的（有拼接痕迹、五官错位）。

3. **根因结论**（四条相互独立的证据：原版损失代码的行号、我方配置、对比数据、
   用户目击）：原版的质感来自 pass2 位置上每步全帧的分布监督（对抗×10 + 特征
   匹配×100，参照物是真实照片，见 `reference/orig_WarpGAN-main/training/
   coach_inpainting_static.py` L1118-1196）。diffusion 版把这一族损失整体关闭后，
   只剩 ε-MSE——它教得出结构和能量，教不出"什么内容配什么质感"，于是空洞区的
   高频来自 SD 预训练先验的平均统计（这就是"沙沙"的本质）。

4. **当前代码（v17-prime）**：按用户指令"拒绝手工门、适配要符合第一性原理"
   实现 §4.3 的机制。冒烟测试全部通过（特征匹配损失触发、判别器步运行、W+
   梯度为零、显存峰值 21.28 GiB 低于 22 GiB 预算、ᾱ_t 解析权重与实测一致）。

## 6. 用户的角色、历次关键质疑，与技术红线

### 6.1 分工与质量防线

方向决策、方法论原则、每个版本的最终裁决（肉眼终审）由**用户**做出；历任 agent
负责读代码、写实现、跑实验、做数据分析。历史证明这道防线不可省略：agent 的
根因分析出过错（旧文档两处被推翻），agent 的实现出过错（基准对比的 FFC bug，
由用户看图发现）。因此对新 agent 的要求：**每个论断给出处；分析必须有对照数据
支撑，只有推理的结论要标注为假设；用户的肉眼终审优先于自动指标；启停训练、
修改配方这类重大动作先请示后执行。**

### 6.2 用户历次关键质疑（都产生了实际后果）

| 用户的质疑/指令 | 结果 |
|---|---|
| 不信任先前的记录 | 合理：旧文档确有两处根因分析被推翻 |
| 怀疑 agent 没有真正读完代码 | 合理：上一任 agent 因未读损失段得出过错误结论；此后两个训练主文件已 100% 通读 |
| "四十多轮都按建议走，怎么跳出循环" | 诊断成立：历轮从未与原版对照、指标无法区分版本——直接催生了基准对比 |
| "t<200 这种感觉怪怪的，要第一性原理" | 成立：清点出一整族硬编码阈值，全部是历史事故的产物，已在当前版本移除 |
| "可能你的代码写错了，人脸是原来角度的" | 属实：抓住了 FFC 复现的 bug |
| "GAN/FM 炸过，是不是实现有问题" | 复盘结论：两次失败都是实现/位置错误，不是这类损失不适配 diffusion |

### 6.3 技术红线（历代实证，违反即重蹈覆辙）

1. 像素/感知损失不能直接作为 ε 的训练目标（历史上两次训练爆炸）——只能走
   x0 对称重加噪路径；
2. 判别器/特征匹配的参照对必须同视角、同噪声水平（v14 因视角错位崩溃）；
3. 判别器的真实样本永远用照片，不用渲染图（否则质感被拉向"塑料"）；
4. W+ 分支只在合成批更新（早期 §17.8 教训）；
5. 训练 timestep 保持全范围 [0,1000)（只训低噪声段会导致输出雾化）；
6. 输出整帧生成，不做硬拼接；续训必须重申全部命令行覆盖并核对生效配置
   （v1-v3 整代事故）；
7. 二值掩码不进监督（产生碎片伪影）；空洞不能长期零监督（高频漂移）。

### 7.7 洞区脏度根因分析（2026-09-18 晚，对照 gpt.md 与代码核实）

**三层根因（全部有代码/数据出处）：**
1. **监督目标分布错位**（gpt.md §4/§6 的原话级预测）：洞区全部参照损失
   （ε-MSE 全 t、ldif、LPIPS）都以 anchor 为目标（`_x0_losses_invsr` 的
   `tgt = out['target_latents']`），anchor 洞区统计 ≠ 照片统计。实测吻合：
   可见区（照片证据监督）W6 达源照片级洁净，洞区（anchor 监督）持续脏——
   "脏"即 anchor 洞区统计与照片统计的残差。
2. **照片参照的对抗损失没有打到洞区**：现有 D 配对仅 `real_p2`（real=照片，
   但作用在 pass2 重建，对 pass1 洞区的转移依赖"pass2 迁移"这一未验证假设）
   和 `synth_x0`（**real=成对渲染 latent，违反红线 #3**，代码注释
   L1298-1299 自证）。**没有任何 D 配对看到 pass1 新视角洞区内容**——部署
   路径上洞区纹理从未被照片统计约束。这解释 adv×0.1 vs ×1.0 对洞区脏度无差：
   打的不是那个靶。
3. **高频相位维度无约束→随数据课程漂移→模式振荡**：ε-MSE/L1/LPIPS 对高频
   相位不敏感；每批 mirror 覆盖率波动大（real_p1_mirror_hole_cov 0.004-0.34）；
   无约束维度跟课程漂移，两臂共享数据顺序故同步（58K 双塌落）。

**修正方向（gpt.md §11-12 处方，未执行的部分）——W7 提案（待用户裁决）：**

### 7.11 参照解法勘察（2026-09-18 深夜，W7 实施前的文献/代码考古）

**① 原版 WarpGAN（最强：代码在库、组件在我们管线里每步都在算）**
