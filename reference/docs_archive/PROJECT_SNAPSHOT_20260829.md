## 1. 任务本质与第一性原理

**任务**：单图新视角人脸合成。核心事实：hole 区域（disocclusion）**不存在真值照片**——那个
视角的照片没有被拍过。一切设计张力源于此。

**证据分级原理（本项目最高原则，用户提出+逐步精化）**：监督/注入强度应与证据强度匹配：

```
源照片 x（结构+纹理，最强） > x_mirror 真照片（纹理+对侧结构）
  > EG3D 渲染（只有结构/几何可信，纹理=塑料） > SD/BrushNet 先验（生成流形，静态）
```

**三个信息通道**（每轮实验都在调这三者的分配）：
1. 条件（BrushNet 5ch 输入：hybrid 图 + mask）；
2. 监督（ε-MSE 的 target + 权重 + 频段）；
3. 注入（bank attention 检索 + W+ tokens）。

**diffusion 第一性原理**：ε-MSE 忠实回归监督目标的分布——目标是什么网络学什么（油画目标
=油画输出）；L2 型损失有均值化天性；不要用弱证据污染强先验；像素/感知损失直接做 x0 目标 =
毒损失（梯度经 1/√(1-ᾱ) 放大毁掉低 t 的 ε）——已两次实证。

## 6. 已确证的技术事实（证据库，防止重复劳动）

1. **沙沙感机理**：盲区高频（<16px 尺度=皮肤质感频段）零监督 → 无锚漂移（14K 0.041→20K
   0.094 持续升；渲染本身高频仅 0.003——不是复制渲染，是自由噪声）；
2. 盲区误差 **94% 在高频段**、6% 在低频（v11@28K 冻结预演）——频段断层与三块制精确吻合；
3. bank 检索 68% 指向渲染（v9/v10 全程稳定）——监督目标指向渲染时检索渲染是降损失捷径；
4. gate 现状：W+ 固定 0.995 常开；reference gate 0.5 预初始化后基本静止；local gate 走低；
5. latent 闭环被毒损失一刀切误杀（理论无毒：不经过 x0/VAE decoder；原版 pass1 唯一监督）；
6. v12 顺带修复了 v4-v11 的隐性 bug：监督权重场 latent 阶跃（13px box + area 下采样）；
7. hole 需要颜色基底（v3.1）；"hole 零监督→崩盘"红线在新环境下未复现（v11/v12 无崩）。
